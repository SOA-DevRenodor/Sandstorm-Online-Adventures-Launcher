# EQOA: Sandstorm

A native client and Windows launcher for EverQuest Online Adventures: Frontiers.
You need your own Frontiers disc image and a game account. Game data is not included.

## Play

1. [Download Sandstorm Online Adventure Launcher.exe](https://github.com/SOA-DevRenodor/Sandstorm-Online-Adventures-Launcher/releases/download/dev/Sandstorm.Online.Adventure.Launcher.exe).
2. Open it. It creates your game folder and downloads the client automatically.
3. Wait for updates, then click **Play**.
4. Choose your disc image when asked and sign in through the game.

The game folder is `%LOCALAPPDATA%\Sandstorm Online Adventure`; launcher Settings
has **Open Game Folder**. The launcher updates itself and the client automatically.
Downloads work without a GitHub account. An optional complete ZIP is available
on the release page for portable installations.

## Features

- Widescreen, mouse, keyboard and controller support.
- Movable HUD elements with independent horizontal and vertical scaling.
- Optional chat tabs, timestamps, text sizing and clickable player names.
- Target of Target, clearer target information and cooldown numbers.
- Effect timers when their duration is known to the client.
- Combat Meter with damage, healing, damage taken and estimated aggro; share
  results in Say, Group or Guild chat.
- Local texture packs and selectable UI styles. PNG edits refresh while playing;
  launcher Settings also includes **Reload Textures** and folder buttons.
- Launcher news from the official wiki, server status and community links.

World replacements go in **texture-packs/Textures**; UI styles go in
**texture-packs/UI**. Switching UI styles requires restarting the game. Your
settings and texture packs are kept when the programs update.
